# 教師解答與評分規準｜差 0.05 Hz，為什麼要等近 20 秒？

## 標準答案與完整推理

### （一）先驗算一列（2 分）

`f₁ = 472 Hz`、`f₂ = 472.2 Hz`：

1. `Δf = |472 − 472.2| = 0.2 Hz`；`T_M = 1/0.2 = 5 s`。
2. `e = |4.97 − 5|/5 × 100% = 0.6%`。

### （二）模型與證據（3 分）

1. 三列檢核量：
   - `Δf = 0.5 Hz`：`q = 1.98 × 0.5 = 0.990`。
   - `Δf = 0.1 Hz`：`q = 9.98 × 0.1 = 0.998`。
   - `Δf = 0.05 Hz`：`q = 19.91 × 0.05 = 0.9955 → 0.996`。
2. 三列的 `|q−1.000|` 依序為 `0.010、0.002、0.004`（末列以取位後判讀；未取位為 `0.0045`），都不超過含端點門檻 `0.020`，所以依命題用判準，模型**通過**。
3. 表一全距：`2.03−1.98 = 0.05 s`。
   - 支持：在本次 `f_c = 370.25–470.25 Hz` 且 `Δf = 0.5 Hz` 的資料中，`T_obs` 只分布於 `1.98–2.03 s`，與模型預測 `2 s` 接近。
   - 限制：節錄表只給各組平均值，沒有原始重複值或不確定度，且中心頻率範圍有限；因此只能說「在已測範圍內未見明顯影響」，不能證明影響恰為零，也不能外推到所有頻率。

### （三）確認性實驗規畫（3 分）

一個完整示例：

- 採 `2 × 3` 因子設計，例如 `Δf = 0.1、0.5 Hz`，`f_c = 370、470、570 Hz`。每一組令 `f₁ = f_c − Δf/2`、`f₂ = f_c + Δf/2`，因此可在固定 `f_c` 時比較不同 `Δf`，也可在固定 `Δf` 時比較不同 `f_c`。
- 每個組合至少以重新建立條紋狀態的方式做 `3` 次獨立重複，將六組順序隨機化或採平衡順序；固定兩聲源振幅、管長與端點條件、保麗龍球種類與數量、溫度、錄影位置等至少兩項。
- 應變量為依同一操作定義量得的 `T_obs`。先比較同一 `f_c` 下不同 `Δf` 的 `T_obs`，再比較同一 `Δf` 下不同 `f_c` 的平均 `T_obs` 與組內變異；也可計算各組 `q = T_obsΔf`。若模型成立，固定 `Δf` 時改變 `f_c`，`T_obs` 應近似不變；改變 `Δf` 時，`T_obs` 應近似按 `1/Δf` 改變，且各組 `q` 接近 `1`。

## 分項評分規準（8 分）

| 小題 | 分數 | 可觀察得分證據 |
|---|---:|---|
| （一）1 | 1 | `Δf = 0.2 Hz`（0.5）；`T_M = 5 s` 且單位正確（0.5）。 |
| （一）2 | 1 | 列出相對誤差代入並得 `0.6%`；只有答案、無可辨識運算可給 0.5。 |
| （二）1 | 1 | 三個 `q` 為 `0.990、0.998、0.996`；每個正確 1/3 分。 |
| （二）2 | 1 | 正確比較三個偏差與含端點門檻並判為通過；只寫「通過」不給滿分。 |
| （二）3 | 1 | 全距 `0.05 s`（0.4）；支持限於已測範圍（0.3）；指出缺原始重複／不確定度或外推受限（0.3）。 |
| （三）1 | 1 | 至少 `2 × 3` 層級，且能同時做到固定 `f_c` 比 `Δf`、固定 `Δf` 比 `f_c`。 |
| （三）2 | 1 | 每組至少 3 次獨立重複（0.3）、順序隨機或平衡（0.2）、至少兩項合理固定條件（0.5）。 |
| （三）3 | 1 | 明列 `T_obs`（0.3）、組間平均及組內變異或 `q` 的比較（0.3）、兩種固定條件下的模型預測（0.4）。 |

**連鎖錯誤：**若學生在（一）誤算 `Δf`，但後續依自己的 `Δf` 正確代入，可保留後續方法分；（二）必須使用指定三列各自的正確 `Δf` 才能取得對應數值分。

## 常見錯誤與診斷

- 把 `T` 寫成與 `Δf` 成正比：未理解倒數模型；可檢查 `0.05 Hz` 對應約 `20 s` 而非更短時間。
- 忘記絕對值或用 `f₁+f₂` 當頻率差：混淆 `Δf` 與 `f_c`。
- 將 `q≈1` 說成「證明模型永遠正確」：把有限範圍、有限精度的支持誤當普遍證明。
- 只換中心頻率卻沒有固定 `Δf`：無法隔離兩個自變項。
- 把連續錄影的相鄰週期當成獨立重複：未重新建立條件，可能低估組內變異。
