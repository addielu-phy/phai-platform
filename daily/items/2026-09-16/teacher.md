# 教師答案與評分規準｜999 到底是不是 999？

> 高中一年級自然科／探究與實作｜建議 8–12 分鐘｜共 10 分

官方研究以水霧、假樹條帶與下游空品儀建構風洞模型；報告明載監測儀 PM2.5 上限為 999 μg/m³，並比較假樹條帶位置與濃密度。[2]

本題沿用裝置邏輯與上限概念，但表內風速、峰值濃度及品質規則全是**命題改編數據**，不是官方報告的原始量測值；所有算術以 `qa/independent_recalculation.py` 及 `qa/independent_recalculation.json` 獨立重算。

## 一、標準答案與關鍵推理

### （一）資料品質與最低減幅（4 分）

1. 排除 **D 位置第 4 次（D4）**。其風速為 \(0.72\ \mathrm{m/s}\)，低於預先訂定且含端點的納入範圍 \(0.95\le v\le1.05\ \mathrm{m/s}\)。排除依據在看 PM2.5 數據之前已訂定，因此不是因結果不合期待才刪除。

2. A 組 4 次均通過風速規則；把兩個設限值暫以 999 代入：

\[
\overline C_{A,\mathrm{LB}}
=\frac{999+940+999+960}{4}
=\frac{3898}{4}
=974.5\ \mathrm{\mu g/m^3}.
\]

由於兩個 `999＊` 的真值只知 \(C\ge999\)，所以 A 組真實平均峰值只可判定為 \(\overline C_A\ge974.5\ \mathrm{\mu g/m^3}\)。

3. D 組排除 D4 後：

\[
\overline C_D
=\frac{410+430+420}{3}
=\frac{1260}{3}
=420.0\ \mathrm{\mu g/m^3}.
\]

4. 

\[
R_{\min}
=\frac{974.5-420.0}{974.5}\times100\%
=56.900974\ldots\%
\approx\boxed{56.9\%}.
\]

這是**最低減幅**，不是精確減幅。令 A 組真實平均為正值 \(x\)，則減幅 \(1-420/x\) 會隨 \(x\) 增大而增大；而 \(x\ge974.5\)，故真實減幅至少為 56.9%。

### （二）證據能說到哪裡？（3 分）

1. 比較方向與量化界線：D 的平均峰值低於 A；依現有顯示值，D 相對 A 的峰值最低減幅為 56.9%，也就是「至少降低 56.9%」，不是固定效果量。A1、A3 的 `999＊` 是右設限值，故更高的真值只會使真實減幅更大。
2. 結論須保留的條件，任列兩項：本題風洞裝置、20 秒噴霧、同一濃密假樹條帶、只納入 \(0.95\le v\le1.05\ \mathrm{m/s}\) 的試次、相同下游儀器位置。原研究也把假樹條帶位置、密度與噴霧時間視為需控制或比較的條件。[2]
3. 合理的戶外差異與影響示例，答一組即可：
   - 真實風向、風速與紊流會隨時間改變，可能使汙染物繞流、滯留或稀釋，減幅不會固定；
   - 水霧不等同各種真實 PM2.5 粒子的粒徑、密度與表面性質，植被攔截效率可能改變；
   - 真樹的葉面、孔隙、樹冠高度與季節不同於濃密假樹條帶，可能改變穿透與沉積；
   - 戶外有多個移動汙染源與背景濃度，單一上游噴霧源的比較未必可直接外推。

### （三）把「位置」檢驗得更公平（3 分）

題目已固定 A／D 位置比較及峰值應變因，不對重述這兩項給分。一個完整示例：

1. 控制同一假樹條帶及濃密度；每次使用同一條帶、方向與折疊方式。
2. 控制噴霧量；使用同一噴霧器設定與 20 秒發送時間。其他可接受控制包括風速／風向、風洞幾何、儀器位置、回復背景條件、溫濕度與儀器設定。
3. A、D 各做 10 次。
4. 每次重新讓風洞回到預先訂定的背景濃度，再開始新的噴霧與量測；每次只產生一個主要峰值，不把同一次的多個時間點當成多次。
5. 用亂數表、電腦亂數或抽籤決定 A／D 執行順序；亦可在每個區集內各做一次 A、D，再隨機決定先後。
6. 改用經校正且量程高於預期峰值的 PM2.5 監測儀；或在正式收集資料前，以不納入分析的預試統一降低兩組水霧輸出，使所有正式值落在線性量程內。

## 二、解析式評分規準

| 小題 | 配分要素 | 得分條件 |
|---|---|---|
| （一）1 | 正確排除 | 指出 D4，並以 \(0.72<0.95\ \mathrm{m/s}\) 解釋；只寫「300 是異常值」不得分。 |
| （一）2 | A 組下限平均 | 正確列式並得 \(974.5\ \mathrm{\mu g/m^3}\)，且知道這是下限。 |
| （一）3 | D 組平均 | 排除 D4 後正確列式並得 \(420.0\ \mathrm{\mu g/m^3}\)。 |
| （一）4 | 最低減幅 | 正確代入並得 \(56.9\%\)，標示為最低／至少而非固定值。 |
| （二）1 | 比較與量化 | 寫出 D 低於 A，且最低／至少減幅為 56.9%。 |
| （二）2 | 條件邊界 | 從題幹正確列出兩項不可省略的實驗條件；每項 0.5 分。 |
| （二）3 | 外推限制 | 說出一項真實戶外與風洞的具體差異，並連結可能造成的結果改變。 |
| （三）1 | 控制變因一 | 變因具體，並說明如何維持相同；0.5 分。 |
| （三）2 | 控制變因二 | 與前項不同、具體，並說明如何維持相同；0.5 分。 |
| （三）3 | 試次數 | 每位置提出同一個具體整數，且皆不少於 8 次；0.5 分。 |
| （三）4 | 獨立試次 | 說明重置／回復背景後重新執行，不把同次連續讀值當獨立試次；0.5 分。 |
| （三）5 | 隨機順序 | 提出可執行的亂數、抽籤或隨機區集方法；0.5 分。 |
| （三）6 | 避免設限 | 提出較高量程儀器或正式實驗前統一調低兩組輸出等不依結果改動的可行方法；0.5 分。 |

### 部分給分與答案傳播

- （一）若只發生單一步驟算術錯誤，但納入／排除、設限方向、公式與後續代入均一致，可在受影響的 1 分格給 0.5 分。
- （二）1 若沿用學生在（一）算錯的百分比，但比較方向及「最低／至少」概念正確，可保留 0.5 分；同一算術錯誤不重複全扣。
- 合理等價的戶外限制與實驗方案均可得分，不要求與示例逐字相同。

## 三、常見錯誤與診斷

| 常見錯誤 | 反映的迷思／診斷 |
|---|---|
| 因 300 與其他值差很大才刪 D4 | 以結果挑資料；未使用預先規則與控制變因。 |
| 把所有 999 當作真值恰為 999 | 未理解儀器上限造成的右設限。 |
| 把 D4 納入 D 平均 | 忽略已明定且含端點的資料品質規則。 |
| 寫「降低 56.9%」而不寫至少／最低 | 把下限估計誤當精確效果量。 |
| 由風洞直接下結論「所有戶外情況都有效」 | 混淆模型內部證據與外部效度。 |
| 後續實驗只做 A 一次、D 一次 | 未處理試次變異與執行順序偏差。 |
| 為避免 999 而只把 999 改記成 1000 | 竄改資料，沒有改善量測範圍。 |
| 用燃燒方式製造真實 PM2.5 | 忽略安全與健康邊界；本題只規畫安全水霧風洞。 |
