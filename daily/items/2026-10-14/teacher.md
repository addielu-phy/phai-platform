# 教師答案與評分規準｜1.7 cm 的條紋，真的來自駐波嗎？

**總分：9 分｜建議作答時間：10 分鐘**

## 一、標準答案與獨立計算

### （一）公式、波長、節線距離與相對偏差（3 分）

1. **M1 正確。**
   - `v/f` 的單位為 `(m·s⁻¹)/(s⁻¹) = m`，符合波長單位。
   - `fv` 的單位為 `(s⁻¹)(m·s⁻¹) = m·s⁻²`，不是長度。
2. `λ = v/f = 1500/40000 m = 0.0375 m = 3.75 cm`。
   - `d模型 = λ/2 = 1.875 cm → 1.88 cm`。
3. 中間值不取位：
   - `E = |1.7 − 1.875|/1.875 × 100% = 9.333…% → 9.3%`。

**來源算式稽核：**原報告 p.11 顯示 `λ=fv`，但同一行顯示的 `0.0375 m = 3.75 cm` 實際對應 `v/f`；原報告接著把半波長寫為約 `1.8 cm`。[1] 本題不複製錯式為正確物理，學生版提供兩個候選式並要求以量綱判斷；教師答案明示校正。學生版的 `1.88 cm` 是依本題取到 `0.01 cm` 的顯示規則，不是把來源的「約 1.8 cm」改稱更精密的來源量測。

### （二）證據界線（2 分）

**不同意 R 的「已足以證明」措辭。**

- 數值面：觀察間距約 `1.7 cm`，模型值依本題輸入為 `1.875 cm`，相對偏差約 `9.3%`。這可說是與模型在量級上相容的初步證據，但不是零偏差。
- 限制面：題幹沒有四個相鄰間距的個別值、變異或量測不確定度，因此不能判斷 `9.3%` 是否超出合理變動；也沒有把頻率系統性改變後檢查 `d ∝ 1/f`，所以單一頻率的空間規律仍不能排除其他位置效應。

可接受「資料支持模型但不足以證明因果」或「暫不否定模型，但 R 過強」。若學生只因 `E ≠ 0` 就宣稱模型被完全推翻，未處理來源數值均帶「約」且缺少不確定度，不給完整評鑑分。

### （三）確認性測試示例（4 分）

1. `80 kHz = 80000 Hz`：
   - `d模型 = v/(2f) = 1500/(2×80000) m = 0.009375 m = 0.9375 cm → 0.94 cm`。
   - 亦可由頻率加倍、間距減半得到未取位值 `1.875/2 = 0.9375 cm`。
2. **控制條件示例：**固定水溫，因水溫會影響水中聲速 `v`；若溫度隨頻率條件一起改變，間距差異不能只歸因於 `f`。其他可接受者包括水深、鋁箔尺寸與厚度、浸入位置與垂直度、超音波功率、震盪時間及槽體幾何，但必須說明混淆途徑。
3. **獨立重複與順序：**每頻率至少 5 張新的同批鋁箔紙；每次重新放置同規格鋁箔、恢復同一水深與溫度範圍、依相同時間震盪，完成一次才換新紙。先用亂數排出 10 次以上的 `40/80 kHz` 交錯順序，避免設備升溫或時間漂移與頻率綁在一起。同一張鋁箔上的多個間距是同一試次內的量測，不冒充多張獨立重複。
4. **結果與事前規則示例：**每張鋁箔量測至少 3 個相鄰密集線間距，先求該張平均，再比較兩頻率的跨紙平均。事前規則可訂為：「若模型成立，`d80/d40` 應落在 `0.45–0.55`；超出則判為不符合本次預設容許範圍。」也可用兩組 `f×d` 相差不超過 `10%` 的等價規則。這個 `10%` 是命題示例的事前判準，不是原報告結論；若學生提出其他合理、明確且事前設定的數值規則，可給分。

## 二、分項評分規準

| 分項 | 1 分條件 | 0 分或不完整 |
|---|---|---|
| （一）公式與量綱 | 選 M1，並正確寫出 `(m/s)/(1/s)=m`；同時可指出 M2 不是長度 | 只猜 M1、未做單位分析，或接受 `fv` |
| （一）`λ` 與 `d模型` | `λ=3.75 cm` 且 `d模型=1.875 cm→1.88 cm` | 單位換算錯、把 `λ` 直接當節線距離、先取位造成錯值 |
| （一）`E` | 用未取位 `1.875 cm`，得 `9.3%` | 分母用 `1.7`、漏乘 `100%`、以已取位 `1.88` 導致不符規則 |
| （二）數值證據 | 正確使用 `E≈9.3%`，解釋為相容程度而非自動證明或自動否證 | 只說「很接近」或「不相等」而無數值 |
| （二）證據缺口 | 指出缺少間距個別值／變異／不確定度，或缺少改變頻率的可否證測試，並據此拒絕「已證明」 | 只重述 4 條線或 20 張；把重複張數直接當因果證明 |
| （三）80 kHz 預測 | `0.9375 cm→0.94 cm` | 頻率加倍卻預測間距加倍；忘記 `/2` |
| （三）控制 | 一項相關控制及明確混淆理由 | 只列名稱、無理由；把頻率列為固定 |
| （三）獨立試次與順序 | 新鋁箔形成獨立試次，具體重置，且 40/80 kHz 隨機交錯 | 同張紙多取幾段冒充獨立重複；先做完一種頻率且不處理漂移 |
| （三）結果與事前規則 | 寫出間距量測／跨紙整理，並以 `d80/d40≈0.5`、`f×d≈常數` 或等價明確數值範圍判定 | 只寫「看是否接近」、結果出來後才選容許範圍 |

**傳遞給分：**（一）若公式與方法正確但純算術錯誤，後續 `d模型`、`E` 可依學生自己的未取位值一致計算後給方法分。（三）若學生沿用自己前題的 `d40` 並正確使用頻率反比，可給預測方法分；數值答案仍須標示更正值。

## 三、常見錯誤與診斷

1. **只看數字、不看量綱：**因報告印有 `fv` 就照抄；應檢查結果是否為長度。
2. **把波長當相鄰節線距離：**漏用 `d=λ/2`，得到 `3.75 cm`。
3. **過早取位：**先把 `1.875` 寫成 `1.88` 再算偏差，違反題目規則。
4. **小偏差＝證明：**忽略近似輸入、量測不確定度與競爭解釋。
5. **非零偏差＝推翻：**沒有比較變異或事前容許範圍。
6. **偽重複：**把同一張鋁箔上的多段間距視為多張獨立試次。
7. **時間漂移混淆：**先做完 40 kHz 再做 80 kHz，使水溫或設備狀態和頻率同時改變。

## 五、公平性與安全

- 學生版定義全部非例行符號、公式、單位換算、取位與模型端點，不需閱讀原報告。
- 原報告的 `1.7 cm` 與 `1500 m/s` 均保留「約」的性質；額外小數位只作明示的命題計算顯示，不冒充來源精度。
- 開放式規畫按可觀察要素給分，不要求特定品牌、程式或超出題幹的空蝕機制。
- 學生只做紙上分析；教師示範須遵守學生版的停機、拔電、加蓋與不得把手伸入運轉槽的安全邊界。
