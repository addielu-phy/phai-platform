# 教師答案與評分規準｜少掉的 2，會讓平衡常數變多少？

## 標準答案與獨立計算

### （一）稽核滴定計算（2 分）

2.00 mL 樣品中：

- `n(Cu²⁺) = 2(0.125 − a) mmol`
- `n(I₃⁻) = 2(0.5a) = a mmol`

滴定劑用量為 `0.0100 mol/L × 25.30 mL = 0.253 mmol`。因此應選紀錄乙：

`3[2(0.125 − a)] + 2a = 0.253`

`0.750 − 6a + 2a = 0.253`，故 `a = 0.12425 mol/L`。

紀錄甲若照字面解會得到 `a = 0.12200 mol/L`，與原報告同段列出的 2.00 mL 取樣量不一致。原報告 PDF p.12（印刷 p.11）先寫 `n(Cu²⁺)=2(0.125−a) mmol`，隨後顯示的總量式卻少了此因子 2；本題採量綱與取樣量一致的更正式。[1]

### （二）重算平衡常數（2 分）

用未提前取位的 `a = 0.12425`：

- `[Cu²⁺] = 0.125 − 0.12425 = 0.00075 mol/L`
- `[I⁻] = 0.875 − 2.5(0.12425) = 0.564375 mol/L → 0.56438 mol/L`
- `[I₃⁻] = 0.5(0.12425) = 0.062125 mol/L → 0.06213 mol/L`

`K = 0.062125 ÷ [(0.00075)²(0.564375)⁵] = 1,928,879.229…`

故 `K = 1.93 × 10⁶`（3 位有效數字）。

原報告此配比列值為 `1.98 × 10⁶`；它同段還印出 `0.125 − 0.1242 = 0.00075`，但左式照顯示位數計算應為 `0.0008`。本題不複製顯示誤差為正確數學，而依題面原始輸入與未取位的 `a` 重算。[1]

### （三）資料一致，不等於方法準確（2 分）

`K平均 = (2.04 + 1.88 + 1.98) × 10⁶ ÷ 3 = 1.966666… × 10⁶ = 1.97 × 10⁶`

`R = (2.04 − 1.88) ÷ 1.966666… × 100% = 8.13559…% = 8.1%`

因 `8.1% ≤ 10.0%`，依題定判準，跨配比內部一致性可接受。

不接受主張。理由可採下列任一完整表述：

1. `R` 只比較同一方法所得三值彼此是否接近；沒有可接受參考值，不能由此判斷準確度。
2. 原報告說明滴定在不同天進行且未嚴格控溫；未控制溫度時，三值接近不能證明溫度無影響，也不能排除共同的系統偏差。[1]

### （四）規畫溫度檢驗（2 分）

一個完整方案例：固定初始配比 `1:7`，設定 `20.0、25.0、30.0 °C` 三個溫度層級；固定原液濃度與批次、總混合體積、平衡等待時間、2.00 mL 取樣、滴定劑濃度、終點判準與器材。各溫度至少製備 3 份**獨立混合樣品**，隨機化測量順序；每份計算 `K`，比較各溫度的平均 `K` 與組內變異。若溫度組間差異相對於組內變異具有一致方向，才支持溫度影響本方法所得 `K`。只重複讀同一瓶樣品不算獨立重複。

## 分項評分規準

| 小題 | 可觀察表現 | 分數 |
|---|---|---:|
| （一）1 | 寫出 `2(0.125−a) mmol` | 0.5 |
| （一）1 | 寫出 `a mmol`，或完整寫成 `2(0.5a) mmol` | 0.5 |
| （一）2 | 選紀錄乙並以 2.00 mL 取樣量或單位說明理由 | 0.5 |
| （一）2 | 正確解得 `a = 0.12425 mol/L` | 0.5 |
| （二） | 三個平衡濃度皆正確；兩個正確給 0.5，僅一個正確給 0.25 | 0.75 |
| （二） | 正確列出 `K` 代入式 | 0.5 |
| （二） | 得 `1.93 × 10⁶`，3 位有效數字 | 0.75 |
| （三）1 | `K平均 = 1.97 × 10⁶` | 0.5 |
| （三）1 | `R = 8.1%` 並判為可接受 | 0.5 |
| （三）2 | 不接受主張；說明內部一致性不等於準確度，或指出未控溫不能支持「溫度無影響」 | 1.0 |
| （四）1 | 明列至少 3 個溫度層級，並固定至少 2 項其餘條件 | 1.0 |
| （四）2 | 每溫度至少 3 份獨立樣品；以 `K` 為應變量，比較組間平均與組內變異 | 1.0 |

**總分：8 分。**（二）採連鎖錯誤原則：若 `a` 錯但三個濃度、`K` 公式與取位均與自己的 `a` 一致，最多可得 1.25 分；（三）必須使用題表三值，不承接（二）。

## 常見錯誤與診斷

| 常見錯誤 | 對應迷思 | 教學回饋 |
|---|---|---|
| 選紀錄甲 | 把濃度數值直接當 mmol，忽略 2.00 mL 取樣量 | 先寫 `n = CV`，用 `1 M·mL = 1 mmol` 檢查每一項 |
| 以 `2(0.125−a)` 當滴定劑用量 | 忽略 `Cu²⁺ : S₂O₃²⁻ = 1 : 3` | 分開寫「樣品物質量」與「滴定劑需求量」 |
| 把固體 `CuI` 放入 `K` 分子 | 未依題定平衡式處理純固體 | 本題已明示純固體不列入 |
| 先把 `0.564375` 取位再算 `K` | 中間值過早取位 | 只在最後按題意取位 |
| 三個 `K` 接近就稱準確 | 混淆精密／一致與準確 | 準確度需要參考值或獨立方法 |
| 每個溫度只測同一瓶三次 | 把重複讀值當獨立重複 | 每次要重新配製、反應與滴定獨立樣品 |
| 同時改溫度與初始配比 | 無法把差異歸因於溫度 | 檢驗單一因子時固定其餘條件 |

## 時間、課綱、Bloom 與安全

- **預估時間：**讀題 2 分鐘；（一）2 分鐘；（二）2–3 分鐘；（三）2 分鐘；（四）2 分鐘，合計約 10–11 分鐘。
- **作答歷程：**單位／計量稽核、獨立計算、跨資料一致性判讀、科學主張評鑑、控制變因與獨立重複規畫。
- **108 課綱：**`tr-Ⅴc-1`（以數理演算與證據理解並指出論點限制）、`tc-Ⅴc-1`（比較科學資料解釋及程序合理性）、`pe-Ⅴc-1`（辨明變項、測試次數與可能誤差）、`pa-Ⅴc-1/2`（以數學整理資料並比較檢核結果）。[6]
- **Bloom：**應用 3 分、分析 3 分、評鑑 1 分、創造／規畫 1 分。
- **公平性：**所有化學計量、公式、單位換算、取位與判準均提供；不要求記憶滴定反應或平衡常數單位慣例；允許計算機與連鎖錯誤方法分。
- **安全：**學生只做紙筆分析。若延伸實作，限合格教師在通風良好實驗室執行，穿戴個人防護具，含銅與碘物種廢液集中回收，不得排入水槽。

## 來源與改編界線

反應模型、1:7 配比、取 2 mL、`0.01 M × 25.3 mL`、報告顯示式與三個原報告 `K` 列值取自官方 PDF pp.7、12、15（印刷 pp.6、11、14）。原報告只顯示 `1 M`、1 mL、7 mL、8 mL、2 mL、`0.01 M`、25.3 mL；學生版增加的末位 0 均明示為命題用名目輸入，不當作來源量測精度。本題新增 `R`、`R ≤ 10.0%` 判準、準確度定義、至少三個溫度與每層至少三次獨立重複的確認方案，均屬命題改編，不宣稱是原研究採用的判準。[1]
